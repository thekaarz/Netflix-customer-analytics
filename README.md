# Netflix Customer Analytics Dashboard

An interactive Power BI dashboard that analyzes customer behavior and subscription patterns using a sample dataset of 5,000+ customer records.

## Overview

The dashboard turns raw customer data into a clear, filterable view of how customers subscribe and watch. It is built to answer questions such as:

- Which subscription types are most common?
- Which devices do customers use most?
- Which genres get the most watch hours?
- How do these patterns change by region and gender?

## Features

- KPI cards for headline metrics
- Charts for subscription types, device usage, and genre-wise watch hours
- Region and Gender slicers for instant filtering
- DAX measures for calculated metrics

## Tech Stack

| Tool | Purpose |
|:--|:--|
| Power BI | Dashboard design and visualization |
| DAX | Measures and calculations |

## Dataset

Sample dataset of 5,000+ customer records. It is used for learning and practice only and contains no sensitive personal data.

## How to Open

1. Download the `.pbix` file from this repository.
2. Open it in Power BI Desktop.
3. Use the slicers to explore the data.
